# SVG_Composer
1. Хранение: как устроена «библиотека
Сервис не использует базы данных или серверы. Вся работа происходит прямо в браузере. Исходные SVG-файлы хранятся на вашем компьютере в строгой структуре папок: сначала размер (L или S), затем категория (Главные или Фоновые объекты). Названия папок сами по себе служат навигацией — программа понимает, что лежит внутри, просто читая путь к файлу. 
Когда вы загружаете папку, браузер считывает все SVG-файлы и создает их «каталог» в оперативной памяти. Исходные файлы при этом остаются нетронутыми — сервис держит их в памяти как эталонные образцы, готовые к копированию.
2. Извлечение: как сервис находит нужные элементы
У пользователя есть три способа достать объект из библиотеки.
Первый — визуальный: вы просто кликаете по превью объекта в левой панели. 
Второй — текстовый поиск: вы вводите название (например, «лампа»), и сервис фильтрует каталог по именам файлов и тегам.
Третий, самый умный — метафорический. У каждого объекта есть набор скрытых тегов (синонимов). Например, у кошелька есть теги «деньги», «финансы», «бизнес». Когда вы вводите фразу «безопасный бизнес», программа разбивает её на слова и ищет совпадения в тегах. Она подсчитывает, у какого объекта больше всего совпадений, и автоматически предлагает собрать композицию из этих элементов. 
3. Переиспользование: как элементы попадают на холст и меняются
Ключевой принцип: сервис **никогда не меняет оригиналы**. Когда вы выбираете объект, программа делает его точную цифровую копию (клон) и помещает на холст. 
С этой копией можно делать что угодно: двигать, поворачивать, менять размер. Благодаря тому, что это векторная копия, качество картинки не теряется. Порядок слоев (кто впереди, кто сзади) настраивается простым списком. Фоновые объекты по умолчанию автоматически отправляются на задний план и становятся полупрозрачными, чтобы не перекрывать главные.
4. Умная перекраска
Когда вы применяете новую цветовую схему, сервис не просто заливает всё одним цветом. Он смотрит на цвета внутри клона, выстраивает их по порядку от самого темного к самому светлому и по очереди заменяет на цвета из выбранной палитры. При этом соблюдается строгое правило дизайна: если объект главный — он получает все цвета схемы. Если это фон — сервис использует только черный, белый и серые оттенки, чтобы цвета главных объектов никогда не попадали на фон.
5. Экспорт
Когда композиция собрана, сервис берет всё, что сейчас находится на холсте, и упаковывает обратно в один чистый файл формата SVG. Все элементы остаются векторными путями, никакой пиксельной графики не создается. Этот файл можно скачать и продолжить редактировать в любом графическом редакторе.
Был использован Deepseek и Gemini
